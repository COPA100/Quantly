# Engine benchmarks

Generated by `python benchmarks/run_benchmarks.py`. Each C++ kernel is timed against a pure-python loop and a numpy-vectorized baseline across problem sizes. Times are the best of adaptive repeats; lower is better and speedups are C++ against each baseline. Absolute numbers are machine-dependent; the ratios are the point.

Environment: Python 3.14.0, numpy 2.3.4.

## Takeaways

- **Drawdown / underwater duration** is the clear C++ win: a sequential peak-to-trough scan numpy cannot vectorize, so the compiled loop pulls well ahead of both baselines.
- **Monte Carlo VaR** ties numpy: the simulation vectorizes cleanly, so numpy's batched normal draws match the C++ loop. C++ still beats the pure-python loop by roughly an order of magnitude.
- **Correlation** goes to numpy: it dispatches to multithreaded BLAS, which a naive single-threaded C++ triple loop will not beat. C++ still crushes pure python.

The engine earns its keep on the path-dependent metrics; where numpy is already fast the worker's fallback loses nothing.
